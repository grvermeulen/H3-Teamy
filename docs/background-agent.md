# Background Agent usage

Use Cursor Background Agent to offload repetitive or parallelizable work:

- Lint fixes and simple refactors
- Generating or expanding unit/integration tests
- Scanning for TODOs and dead code

Suggested prompts:

- "Fix ESLint warnings across `src/components`"
- "Add tests for `src/lib/training.ts` covering edge cases"

Monitor status, provide follow-ups, or take over as needed.
